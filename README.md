# 🩸 Blood Bank Donor System

## Overview
The **Blood Bank Donor System** is a real-time web application designed to address the urgent need for blood donors in emergency situations. Unlike traditional blood banks that primarily store and distribute blood units, this system focuses on connecting patients with potential blood donors located nearby. By leveraging GPS technology, the system identifies and tracks the closest available donors, facilitating rapid response and better coordination between donors and patients.

---

## Features
- **Real-Time Donor Location Tracking**: Utilize GPS to find and display nearby donors in real-time.
- **User Registration and Authentication**: Secure registration and login for both donors and recipients.
- **Donor Profile Management**: Donors can manage their profiles, including blood type, availability status, and contact information.
- **Search Functionality**: Patients can search for donors based on blood type and location.
- **Admin Panel**: Administrators can manage user accounts, monitor system activity, and oversee the overall operation.
- **Responsive Design**: Accessible on various devices, including desktops, tablets, and smartphones.
